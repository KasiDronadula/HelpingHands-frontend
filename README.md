# 🩸 Helping Hands - Blood Donor Finder (Frontend)

Helping Hands is a responsive web application that helps users find nearby blood donors instantly during emergencies.  
This frontend is built using React and connects with a Spring Boot backend.

---

## 🚀 Features

- 🔍 Search blood donors by blood group and distance  
- 📍 Automatic location detection (Geolocation API)  
- 🔐 User authentication (Login & Register)  
- 🩸 Become a donor  
- 👤 Profile management  
- 📱 Fully responsive design  
- ⚡ Fast API integration  

---

## 🛠 Technologies Used

- ⚛️ React.js  
- 🎨 CSS3  
- 🔗 Axios / Fetch API  
- 🌐 React Router  
- 📍 Geolocation API

## ⚙️ Installation & Setup

```bash
# Clone repository
git clone https://github.com/KasiDronadula/HelpingHands-Frontend.git

# Navigate to project
cd HelpingHands-Frontend

# Install dependencies
npm install

# Run project
npm run dev
```
